# Method Type System — Aligned with CPython

## Overview

PyGDS's method type system strictly aligns with CPython's six underlying function/method types. Each type has a different `type()` output and different behavioral semantics in the Python interactive environment. PyGDS returns names consistent with CPython through the `_type_name()` method.

These six types are defined in `pygds.gd`, plus an additional Property descriptor type.

| PyGDS Class | CPython Equivalent |
| :--- | :--- |
| `PyGDS.DSLFunction` | `PyFunction_Type` |
| `PyGDS.DSLBuiltinFunction` | `PyCFunction_Type` |
| `PyGDS.DSLMethod` | `PyMethod_Type` |
| `PyGDS.DSLMethodDescriptor` | `PyMethodDescr_Type` |
| `PyGDS.DSLWrappedDescriptor` | `PyWrapperDescr_Type` |
| `PyGDS.DSLMethodWrapper` | `PyMethodWrapper_Type` |
| `PyGDS.DSLProperty` | `PyProperty_Type` |

---

## Type Reference Table

| PyGDS Class | `_type_name()` Return Value | CPython Type | Description |
| :--- | :--- | :--- | :--- |
| `DSLFunction` | `"function"` | `PyFunction_Type` | User-defined ordinary functions / static methods |
| `DSLBuiltinFunction` | `"builtin_function_or_method"` | `PyCFunction_Type` | Built-in functions or bound built-in methods |
| `DSLMethod` | `"method"` | `PyMethod_Type` | User-defined bound methods (instance methods, class methods) |
| `DSLMethodDescriptor` | `"method_descriptor"` | `PyMethodDescr_Type` | Class-level non-magic built-in method descriptors (e.g. `str.upper`) |
| `DSLWrappedDescriptor` | `"wrapper_descriptor"` | `PyWrapperDescr_Type` | Class-level magic method descriptors (e.g. `int.__add__`) |
| `DSLMethodWrapper` | `"method-wrapper"` | `PyMethodWrapper_Type` | Instance-level magic method wrappers (e.g. `(1).__add__`) |
| `DSLProperty` | `"property"` | `PyProperty_Type` | Data descriptor generated by the `@property` decorator |

## Behavioral Comparison: Access Semantics Consistent with Python

The following shows how each method type is accessed in PyGDS, fully consistent with CPython's behavior.

```python
# === DSLBuiltinFunction (has __self__) ===
"hello".upper           # → builtin_function_or_method
                        #    DSLBuiltinFunction(name="upper", callback=..., __self__=DSLString("hello"))

# === DSLMethodDescriptor (class-level access, no instance) ===
str.upper               # → method_descriptor
                        #    DSLMethodDescriptor(name="upper", callback=...)

# === DSLWrappedDescriptor (class-level magic method descriptor) ===
int.__add__             # → wrapper_descriptor
                        #    DSLWrappedDescriptor(name="__add__", callback=...)

# === DSLMethodWrapper (instance-level magic method wrapper) ===
(1).__add__             # → method-wrapper
                        #    DSLMethodWrapper(descriptor=..., bound_self=DSLInteger(1))

# === DSLMethod (user-defined bound method) ===
obj.method              # → method
                        #    DSLMethod(instance=obj, function=DSLFunction(...), interp=...)

# === DSLFunction (class-level user method / static method / top-level function) ===
MyClass.method          # → function       [ordinary method accessed on the class]
MyClass.static_method   # → function       [staticmethod accessed on the class]
obj.static_method       # → function       [staticmethod accessed on the instance, not bound]
```

## Detailed Explanation of the Seven Method Types

| Method Type | Located In | CPython Equivalent | `_type_name()` Return Value |
| :--- | :--- | :--- | :--- |
| [DSLFunction](#dslfunction) | `PyGDS.DSLFunction` | `PyFunction_Type` | `"function"` |
| [DSLBuiltinFunction](#dslbuiltinfunction) | `PyGDS.DSLBuiltinFunction` | `PyCFunction_Type` | `"builtin_function_or_method"` |
| [DSLMethod](#dslmethod) | `PyGDS.DSLMethod` | `PyMethod_Type` | `"method"` |
| [DSLMethodDescriptor](#dslmethoddescriptor) | `PyGDS.DSLMethodDescriptor` | `PyMethodDescr_Type` | `"method_descriptor"` |
| [DSLWrappedDescriptor](#dslwrappeddescriptor) | `PyGDS.DSLWrappedDescriptor` | `PyWrapperDescr_Type` | `"wrapper_descriptor"` |
| [DSLMethodWrapper](#dslmethodwrapper) | `PyGDS.DSLMethodWrapper` | `PyMethodWrapper_Type` | `"method-wrapper"` |
| [DSLProperty](#dslproperty) | `PyGDS.DSLProperty` | `PyProperty_Type` | `"property"` |

### DSLFunction

A function defined by the user through the `def` keyword, carrying the function declaration AST, closure environment, and method type flag.

```gdscript
class DSLFunction extends DSLObject:
    var declaration: FunctionStmt     # AST node of the function declaration
    var closure: DSLEnvironment       # Closure environment (captured external variables)
    var method_type: int = 0          # 0=ordinary method, 1=classmethod, 2=staticmethod, 3=@property getter, 4=@name.setter, 5=@name.deleter
    var _cls_interp: Interpreter      # Class interpreter reference
```

***Descriptor Protocol***

This is the key to distinguishing the three method behaviors, based on the values of `method_type` and `instance`.

```gdscript
func __get__(instance, owner):
    # staticmethod (method_type == 2)
    if method_type == 2:
        return self                      # Always returns itself, not bound

    # classmethod (method_type == 1)
    if method_type == 1:
        return DSLMethod.new(owner, self, _cls_interp)   # Bound to the class

    # Ordinary method (method_type == 0)
    if instance == null:
        return self                      # Class-level access, returns the raw function
    return DSLMethod.new(instance, self, _cls_interp)    # Instance-level access, bound to the instance
```

| Scenario | `method_type` | `instance` | Return Value |
| :--- | :--- | :--- | :--- |
| Function as `staticmethod`, accessed via class | 2 | null | `self` (DSLFunction) |
| Function as `staticmethod`, accessed via instance | 2 | obj | `self` (DSLFunction) |
| Function as `classmethod`, accessed via class | 1 | null | `DSLMethod(owner, self)` |
| Function as `classmethod`, accessed via instance | 1 | obj | `DSLMethod(owner, self)` |
| Ordinary function (class-level access) | 0 | null | `self` (DSLFunction) |
| Ordinary function (instance-level access) | 0 | obj | `DSLMethod(instance, self)` |

**Call Mechanism:** `DSLFunction`'s own `magic_call()` is a placeholder method that returns `null`. The actual invocation is handled by `Interpreter.call_user_function()`.

### DSLBuiltinFunction

Encapsulates a GDScript `Callable` as a built-in function, distinguishing whether it is bound via the `__self__` field.

```gdscript
class DSLBuiltinFunction extends DSLObject:
    var name: String                  # Function name
    var callback: Callable            # GDScript callback
    var __self__: DSLObject = null    # Bound self object (null = unbound, non-null = bound)
```

**`_dsl_str()` Output Examples**

- When unbound: `"<built-in function print>"`
- When bound: `"<built-in method 'append' of 'list' object>"`

```gdscript
func magic_call(args, kwargs):
    if __self__ != null:
        var full_args = [__self__]     # Automatically prepend self to arguments
        full_args.append_array(args)
        return _wrap(callback.callv([full_args, kwargs]))
    return _wrap(callback.callv([args, kwargs]))
```

When `__self__` is non-null (i.e., already bound by a descriptor), the call automatically inserts `__self__` as the first argument.

---

### DSLMethod

A user-defined bound method. When a user-defined function is accessed through an instance, the descriptor protocol returns this type.

```gdscript
class DSLMethod extends DSLObject:
    var instance: DSLObject       # The instance to which the method belongs
    var function: DSLFunction      # The bound function object
    var interp: Interpreter        # Interpreter reference
```

**`_dsl_str()` Output Example:** `"<bound method MyClass.foo of <MyClass object>>"`

```gdscript
func magic_call(args, kwargs):
    var new_args = [instance]      # Automatically prepend self (the instance) to arguments
    new_args.append_array(args)
    return interp.call_user_function(function, new_args, kwargs)
```

When called, the bound instance is automatically passed as the first argument to the function — this is exactly the origin of the `self` parameter in Python.

### DSLMethodDescriptor

A class-level non-magic built-in method descriptor. Returned when a built-in method is accessed directly on the **class** (e.g., `str.upper`, `list.append`).

```gdscript
class DSLMethodDescriptor extends DSLObject:
    var name: String                # Method name
    var callback: Callable          # GDScript callback
```

**`_dsl_str()` Output Example:** `"<method 'upper' of 'str' objects>"`

***Descriptor Protocol***

```gdscript
func __get__(instance, owner):
    if instance == null:
        return self                         # Class-level access → returns itself (descriptor)
    var bf = DSLBuiltinFunction.new(name, callback)
    bf.__self__ = instance                  # Instance-level access → returns a bound DSLBuiltinFunction
    return bf
```

This is the mechanism that converts `str.upper` (method_descriptor) into `"hello".upper` (builtin_function_or_method).

```gdscript
func magic_call(args, kwargs):
    return DSLBuiltinFunction._wrap_static(callback.callv([args, kwargs]))
```

---

### DSLWrappedDescriptor

A class-level magic method (double-underscore method) descriptor, used for special methods like `__add__`, `__str__`, `__eq__`, etc.

```gdscript
class DSLWrappedDescriptor extends DSLObject:
    var name: String                # Method name (e.g., "__add__")
    var callback: Callable          # GDScript callback
```

**`_dsl_str()` Output Example:** `"<slot wrapper '__add__' of 'int' objects>"`

***Descriptor Protocol***

```gdscript
func __get__(instance, owner):
    if instance == null:
        return self                         # Class-level access → returns itself
    return DSLMethodWrapper.new(self, instance)  # Instance-level access → returns method-wrapper
```

The key difference from `DSLMethodDescriptor` is that after binding, it returns `DSLMethodWrapper` instead of `DSLBuiltinFunction`, resulting in the `_type_name()` distinction between `"method-wrapper"` and `"builtin_function_or_method"`, fully aligned with CPython.

```gdscript
func magic_call(args, kwargs):
    return DSLBuiltinFunction._wrap_static(callback.callv([args, kwargs]))
```

---

### DSLMethodWrapper

An instance-level magic method wrapper. Returned when a magic method is accessed on an **instance** (e.g., `(1).__add__`).

```gdscript
class DSLMethodWrapper extends DSLObject:
    var descriptor: DSLWrappedDescriptor   # The owning descriptor
    var bound_self: DSLObject              # The bound instance
```

**`_dsl_str()` Output Example:** `"<method-wrapper '__add__' of int object>"`

```gdscript
func magic_call(args, kwargs):
    var full_args = [bound_self]            # Automatically prepend self to arguments
    full_args.append_array(args)
    return DSLBuiltinFunction._wrap_static(descriptor.callback.callv([full_args, kwargs]))
```

### DSLProperty

The `@property` decorator converts class methods into attribute access. `DSLProperty` implements the data descriptor protocol (`__get__` / `__set__` / `__delete__`), fully aligned with Python's `property` type.

```gdscript
class DSLProperty extends DSLObject:
    var prop_name: String       # Property name
    var fget                     # Getter function (DSLFunction)
    var fset                     # Setter function (DSLFunction, can be null)
    var fdel                     # Deleter function (DSLFunction, can be null)
    var _cls_interp              # Interpreter reference
```

***Descriptor Protocol***

```gdscript
# __get__: Read the property value
func __get__(instance, _owner):
    if instance == null:
        return self                          # Class-level access returns the property object itself
    if fget == null:
        return DSLNone.new()
    return _cls_interp.call_user_function(fget, [instance], {})

# __set__: Set the property value (requires @name.setter)
func __set__(instance, value):
    if fset == null:
        instance.last_error = "AttributeError: can't set attribute"
        return
    _cls_interp.call_user_function(fset, [instance, value], {})

# __delete__: Delete the property (requires @name.deleter)
func __delete__(instance):
    if fdel == null:
        instance.last_error = "AttributeError: can't delete attribute"
        return
    _cls_interp.call_user_function(fdel, [instance], {})
```

Correspondence of `method_type` in the `Parser`:

| `method_type` | Decorator Syntax | Meaning |
| :--- | :--- | :--- |
| 3 | `@property` | getter — creates a DSLProperty instance |
| 4 | `@name.setter` | setter — sets fset on an existing DSLProperty |
| 5 | `@name.deleter` | deleter — sets fdel on an existing DSLProperty |

**Usage Example:**

```python
class Circle:
    def __init__(self, radius):
        self._radius = radius

    @property
    def radius(self):
        return self._radius

    @radius.setter
    def radius(self, value):
        if value < 0:
            raise ValueError("radius must be non-negative")
        self._radius = value

    @property
    def area(self):
        return 3.14159 * self._radius ** 2  # Read-only property (computed property)

c = Circle(5)
print(c.radius)    # 5 — calls getter
c.radius = 10      # calls setter
print(c.area)      # ~314.159 — computed property
```

## Descriptor Protocol (`__get__`)

The descriptor protocol is the core of the method type system. It implements the automatic binding mechanism in Python when accessing class methods through an instance.

### Protocol Signature

```gdscript
func __get__(instance, owner) -> DSLObject
```

| Parameter | Meaning |
| :--- | :--- |
| `instance` | The instance accessing the method; `null` if it is class-level access |
| `owner` | The class that the method belongs to (`DSLClass`) |

### Summary of `__get__` Behavior for Each Descriptor Type

| Descriptor Type | `instance == null` (Class-level Access) | `instance != null` (Instance-level Access) |
| :--- | :--- | :--- |
| `DSLMethodDescriptor` | Returns itself (`method_descriptor`) | Returns `DSLBuiltinFunction(name, callback, __self__=instance)` |
| `DSLWrappedDescriptor` | Returns itself (`wrapper_descriptor`) | Returns `DSLMethodWrapper(self, instance)` |
| `DSLFunction` (ordinary) | Returns itself (`function`) | Returns `DSLMethod(instance, self)` |
| `DSLFunction` (classmethod) | Returns `DSLMethod(owner, self)` | Returns `DSLMethod(owner, self)` |
| `DSLFunction` (staticmethod) | Returns itself (`function`) | Returns itself (`function`) |
| `DSLProperty` | Returns itself (`property`) | Calls `fget` and returns its result |

## Method Binding in the Attribute Lookup Chain

### Attribute Lookup on DSLObject Instances (`_dsl_getattribute`)

```txt
DSLObject._dsl_getattribute(name):
    1. fields                    ← Check instance attribute dictionary
    2. klass._dsl_getattribute(name)  ← Look up method from the class (along the MRO chain)
       → If found and has __get__ method → method.__get__(self, klass)  ← Bound to the instance
       → Otherwise return the method directly
    3. Return DSLNone
```

### Attribute Lookup on DSLClass (`_dsl_getattribute`)

```txt
DSLClass._dsl_getattribute(attr_name):
    1. methods[attr_name]        ← Check method dictionary
       → If has __get__ method → call __get__(null, self)  ← Class-level access, not bound
       → Otherwise return directly
    2. class_attrs[attr_name]    ← Check class attributes
    3. superclass._dsl_getattribute(attr_name)  ← Traverse the inheritance chain
    4. Delegate to the DSLObject parent class
```

### Visible Binding Locations

All binding through the descriptor protocol occurs at the moment of attribute lookup, i.e., where `_dsl_getattribute` is called.

- **`_dsl_getattribute`** in DSLObject instances — handles instance-level method binding
- **`_dsl_getattribute`** in DSLClass — handles class-level method access (not bound)
- **`_call_magic_or_fallback`** in Interpreter — looks up and binds magic methods from the class's method dictionary when evaluating expressions

## Unified Method Invocation Entry Point `_invoke_func`

`DSLClass._invoke_func` is the unified entry point for invoking methods in a class.

```gdscript
func _invoke_func(func_obj, args_ary, kw_args):
    if func_obj == null:
        return null
    if func_obj is DSLBuiltinFunction:
        return func_obj.magic_call(args_ary, kw_args)   # Built-in function, call directly
    if func_obj is DSLFunction:
        return interp.call_user_function(func_obj, args_ary, kw_args)  # User function, call via interpreter
    return func_obj.magic_call(args_ary, kw_args)        # Others (method-wrapper, etc.), call their own magic_call
```

This method is used by `DSLClass.magic_call()` for `__new__` and `__init__` invocations, ensuring that different types of function/method objects can all be called through a unified entry point.

## Magic Method Registration

### Registration Location

Magic methods are injected into built-in classes in `PyGDS.Interpreter._inject_builtin_methods`.

### Registration Method

```gdscript
func _inject_builtin_methods(class_obj, cls_name):
    match cls_name:
        "int":
            class_obj.methods["__add__"] = DSLWrappedDescriptor.new("__add__", Callable(proto, "magic_add"))
            class_obj.methods["__sub__"] = DSLWrappedDescriptor.new("__sub__", Callable(proto, "magic_sub"))
            class_obj.methods["__mul__"] = DSLWrappedDescriptor.new("__mul__", Callable(proto, "magic_mul"))
            # ...
        "str":
            class_obj.methods["upper"] = DSLMethodDescriptor.new("upper", Callable(proto, "builtin_upper"))
            class_obj.methods["lower"] = DSLMethodDescriptor.new("lower", Callable(proto, "builtin_lower"))
            # ...
        "list":
            class_obj.methods["append"] = DSLMethodDescriptor.new("append", Callable(proto, "builtin_append"))
            # ...
        "dict":
            class_obj.methods["items"] = DSLMethodDescriptor.new("items", Callable(proto, "builtin_items"))
            # ...
        "tuple":
            class_obj.methods["count"] = DSLMethodDescriptor.new("count", Callable(proto, "builtin_count"))
            class_obj.methods["index"] = DSLMethodDescriptor.new("index", Callable(proto, "builtin_index"))
```

### Method Type Distinction

- **Magic methods** (`__add__`, `__sub__`, etc.) → registered as `DSLWrappedDescriptor` → class-level access is `wrapper_descriptor`, instance-level is `method-wrapper`
- **Ordinary instance methods** (`append`, `upper`, `items`, etc.) → registered as `DSLMethodDescriptor` → class-level access is `method_descriptor`, instance-level is `builtin_function_or_method`

### Operator Evaluation Flow

When the interpreter evaluates a binary operation like `a + b`:

1. `evaluate(Binary)` → dispatches based on operator type
2. Calls `_call_magic_or_fallback(left, "__add__", [right], fallback)`
3. If `left` is a `DSLObject` instance → looks up `__add__` along the inheritance chain of `left.klass`
4. Finds `DSLWrappedDescriptor` → calls `__get__(left, left.klass)` → returns `DSLMethodWrapper`
5. Calls `DSLMethodWrapper.magic_call([right])` → automatically inserts `bound_self` → actually calls `magic_add([left, right])`
6. If no magic method is found → falls back to `fallback()` → directly calls `left._dsl_add(right)`
