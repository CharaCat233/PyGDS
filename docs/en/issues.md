
# Known Issues List

This file records known issues where PyGDS diverges from CPython or lacks features, including unfixed, fixed, and won't-fix items, for use in version planning and handover. This file is not a migration of the Issues page in the GitHub repository, but relevant links to the Issues page may be referenced in this file. This file follows the [Code and Documentation Standards](./standards.md#code-and-documentation-standards)

Issues have the following levels:

- **P0**: silently produces wrong results (wrong values / output without an error)
- **P1**: explicit errors or missing features (predictable, never silently wrong values)
- **P2**: edge differences in behavior (different error types / messages, but both sides either error or succeed)

Each issue has a unique ID consisting of a level plus a sub-number, for example `P0-0`. Even after an issue has been resolved, its sub-number is never reused
