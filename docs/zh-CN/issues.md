
# 已知问题清单

本文件记录 PyGDS 与 CPython 不一致或功能缺失的已知问题，包括未修复、已修复和决定不修复项，供版本规划与交接使用。该文件并非 GitHub 仓库中 Issues 页面的迁移版本，但可以在文件中引用 Issues 页面的相关链接。本文件遵守 [代码与文档规范](./standards.md#代码与文档规范)

问题存在以下几个级别：

- **P0**：静默给出错误结果（数值/输出错误但不报错）
- **P1**：明确报错或功能缺失（可预期、不会静默错值）
- **P2**：行为的边缘差异（错误类型/文案不同，但双方都报错或都成功）

每个问题拥有唯一编号，由级别加上子编号组成，例如 `P0-0`。即使该问题已经被解决，其子编号也不会回收使用

## 问题表格汇总

问题汇总如下，表格内状态一栏，可填写：

- 未修复：当前问题仅被记录，暂未对其进行修复
- 已修复：该问题已被修复
- 不修复：暂时不对该问题进行修复

编号列应链接到对应问题章节，发现时间应该按照 `YYYY-MM-DD` 格式书写
